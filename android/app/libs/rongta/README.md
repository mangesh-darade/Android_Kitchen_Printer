# Rongta RTPrinterSDK — manual download required

Official Android SDK is on OneDrive (not auto-downloadable):

https://www.rongtatech.com/sdk/ → **Thermal Printer & Label Printer Android SDK**

After download, place `printer_library.jar` (or the AAR from the ZIP) in this folder.

The app will show `sdkIntegrated: true` in Settings once `com.rt.printerlibrary` classes are on the classpath.
